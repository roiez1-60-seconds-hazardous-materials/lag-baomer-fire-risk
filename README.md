# תחזית סיכון התפשטות אש — ל"ג בעומר

כלי תומך החלטה מבצעי לכבאות והצלה לישראל, להערכת תנאי התפשטות אש בליל ל״ג בעומר על בסיס תחזית מטאורולוגית פנימית (5 מחוזות, 9 שעות).

## תכונות

- **בחירת מחוז ושעה** עם עדכון מיידי של כל המידע
- **ציון סיכון מורכב (0–100)** משוקלל ממהירות רוח, משבים, לחות וגשם
- **משמעויות אופרטיביות** לכל מדד: כיוון התפשטות אש, מרחק גיצים, יובש דלק, רמת מיתון
- **גרף מגמת לילה** עם הדגשת השעה הנבחרת
- **תמונת מצב כלל-מחוזית** — heatmap של כל המחוזות והשעות
- **RTL מלא** עם גופנים עבריים מותאמים (Frank Ruhl Libre + Assistant)

## הפעלה מקומית

```bash
# פתח את index.html בדפדפן — זהו, אין תלויות
open index.html
```
